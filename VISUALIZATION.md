## 🎨 Дизайн Элементы

### Цветовая Схема
- **Основной**: Синий (#3b82f6)
- **Дополнительный**: Фиолетовый (#8b5cf6)
- **Акцент**: Голубой (#06b6d4)
- **Фон**: Темный (#0f1117)
- **Текст**: Белый (#ffffff)

### Анимации
- ✨ **Плавающие орбы** на фоне
- 🌊 **Частицы** анимируются при скролле
- 📱 **Телефон** плывет вверх-вниз
- 🎯 **Карточки** появляются при скролле (slide-up)
- 💫 **Кнопки** светятся при наведении
- 🎪 **Gradient текст** мигает радугой
- ⌨️ **Ripple эффект** при клике на кнопку

### Гифки
- **Telegram** - все иконки используют гифки из GIPHY
- **Размер иконок**: 40-80px в зависимости от контекста
- **Округлые углы**: 8-20px для мягкого вида

---

## 📱 Адаптивность

### Desktop (> 1024px)
- 2 колонки для Download
- Телефон видно слева в Hero
- Полная навигация в Header

### Tablet (768px - 1024px)
- 1 колонка для Download
- Телефон скрыт
- Меню скрыто (можно добавить мобильное меню)

### Mobile (< 768px)
- Все 1 колонка
- Кнопки складываются
- Меньший шрифт
- Компактный header

## 🔧 Технические Детали

### HTML
- Семантическая разметка
- Доступность (alt текст для изображений)
- Meta теги для SEO

### CSS
- CSS Grid и Flexbox
- CSS переменные для цветов
- Media queries для адаптивности
- Плавные переходы (transition)
- Анимации (keyframes)

### JavaScript
- Плавный скролл
- Intersection Observer для анимаций
- Счетчики с анимацией
- Параллакс эффект
- Ripple эффект на кнопках

## 🚀 Как Просмотреть

1. Откройте файл `e:\tgws\index.html` в браузере
2. Используйте Chrome, Firefox, Safari или Edge
3. Отключите блокировщики рекламы (для гифок)
4. Используйте F12 для мобильного вида
