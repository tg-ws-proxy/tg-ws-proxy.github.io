Часто задаваемые вопросы

Это помогает скрывать читы?

Нет. TG-WS-PROXY — инструмент для доступа к Telegram, а не для скрытия чего-либо. Открытый исходный код — проверь сам на GitHub.

Как быстро подключиться?

WebSocket протокол подключается за 15ms. Вместо обхода миллионов серверов — прямое соединение через оптимизированные каналы.

Следы остаются при удалении?

Да, как в Windows — Prefetch, журналы, Корзина. Но наша утилита не оставляет следов — локально, безопасно, без логирования.

Какая ОС нужна?

Windows 10 и Windows 11 (x64). Как и FunTime Checker — нужны права администратора для полного доступа к сетевому уровню.

Это действительно бесплатно?

Да, полностью бесплатно. Исходный код открыт на GitHub — собери сам, предложи свои улучшения и сигнатуры в базу.

Можно ли это собрать самому?

Полностью. Открытый исходный код на GitHub: ft-ws-proxy. Проверь, собери, вноси улучшения в сообщество.
